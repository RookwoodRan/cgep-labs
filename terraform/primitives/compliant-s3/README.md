This module provisions a NIST 800-53–compliant AWS S3 bucket using Terraform, enforcing five controls as code rather than manual configuration:
 server-side encryption at rest (SC-28) via AES-256, a full public access block across all four flags (AC-3), access logging to a dedicated log bucket (AU-3) with that log bucket serving as the audit review location (AU-6), and required compliance tagging plus versioning enforced through the provider's default_tags block (CM-6). Compliance evidence for each control is captured as machine-readable JSON (plan.json and state.json) rather than screenshots, stored in evidence/lab-2-3/, and independently verified against the live AWS resources before teardown.
